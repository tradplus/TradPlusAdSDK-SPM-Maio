# TradPlus Maio Adapter Swift Package

Swift Package Manager support for the TradPlus Maio adapter (15.16.0).

## Installation

```text
https://github.com/tradplus/TradPlusAdSDK-SPM-Maio.git
```

```swift
.package(url: "https://github.com/tradplus/TradPlusAdSDK-SPM-Maio.git", exact: "15.16.0")
```

Third-party dependency: Maio SDK `2.1.6`. Minimum iOS 14.

## Notes

- This package automatically resolves `TradPlusAdSDK` 15.16.0.
- Add `-ObjC` to the app target's `Other Linker Flags` if required.
